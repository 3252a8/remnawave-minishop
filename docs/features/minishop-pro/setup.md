# Установка и лицензия Minishop PRO

Кабинет Cloud выдаёт доступ к выпуску и код установки. Сам магазин, его клиенты, отчёты и цепочки остаются на вашем сервере. Для подготовки понадобятся права в кабинете Cloud и права администратора Minishop.

## Подключить магазин

1. Откройте **Установка** в [кабинете Cloud](https://cloud.minidoc.cc). После оплаты дождитесь готовности доступа. Посмотрите, для какой версии магазина подготовлен выпуск.
2. Выберите способ установки из таблицы ниже. Перед изменением работающего магазина сохраните резервную копию базы и конфигурации. [Резервные копии Minishop](../backups.md).
3. В Cloud получите одноразовый код для этой установки. Откройте **Плагины → PRO → Настройки → Лицензия** в админке своего магазина, вставьте код и нажмите **Активировать**. Если начинаете из Mini App, путь в админку проходит через **Настройки → Панель администратора**.
4. Дождитесь состояния **Активна**. Проверьте список возможностей и откройте раздел **Маркетинг → Аналитика**. Активация применяется сразу.

| Способ | Что сделать |
| --- | --- |
| Комплект образов | Выполните команды входа в реестр и перехода из своего кабинета на сервере магазина. Cloud подбирает совместимый комплект для backend, worker и frontend. Команда перехода сохраняет копию Compose-файла. Для воспроизводимой установки или отката сохраните файл точного выпуска. |
| Подписанный пакет | Если для вашего аккаунта опубликован ZIP для вашей ревизии Minishop, скачайте его в блоке **Пакет плагина PRO**. В админке откройте **Плагины**, загрузите архив, проверьте совместимость, контрольную сумму и издателя по данным Cloud, затем подтвердите установку. После установки активируйте лицензию. [Установка пакетов](../../development/plugins.md). |

## Оплаченный срок и работа офлайн

Версии самого магазина и плагина указаны в админке отдельно. Совместимую пару для вашего выпуска можно сверить с [историей изменений PRO](./changelog.md). Тексты расширения доступны в редакторе переводов Minishop по группам лицензии, лидов, воронки и автоматизаций.

В **Деталях лицензии** показаны оплаченный срок, срок текущей лицензии и следующее обновление. Это три разные даты. Например, магазин может быть оплачен на месяц вперёд, а связь с Cloud понадобится раньше для очередного подтверждения. При временной потере связи установка может работать офлайн до срока, который разрешает сохранённая лицензия. После восстановления связи нажмите **Обновить лицензию**.

| Что видно | Что проверить |
| --- | --- |
| Код отклонён или нет свободного места | Проверьте установку, для которой выпущен код. Использованный код одноразовый. Ненужный ожидающий код можно отозвать в Cloud и освободить слот. |
| Требуется обновление | Сверьте совместимость версии магазина и PRO с выпуском в Cloud. Сохраните диагностический код из деталей лицензии для обращения в поддержку. |
| Срок истёк или лицензия отозвана | Проверьте оплату и состояние установки в Cloud. После восстановления доступа обновите лицензию. Функции проверяются по отдельности, включая право на экспорт. |

## Пауза и переезд

При потере доступа платные расчёты, набор участников и отправка сообщений цепочек приостанавливаются. История цепочек сохраняется. После восстановления их расписание сдвигается на время паузы. Обычные покупки и ручная поддержка Minishop продолжают работать.

При переезде деактивируйте старую установку в Cloud, освободите слот и выпустите код для новой. Старая установка потеряет возможность обновлять лицензию. Для возврата к обычной сборке используйте инструкцию возврата для своего способа установки. Резервная копия Compose-файла восстанавливает конфигурацию образов, а восстановление базы выполняется отдельно.
