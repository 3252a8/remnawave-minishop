# Воронка продаж

В **Маркетинг → Аналитика → Воронка продаж** можно выяснить, сколько людей дошло от регистрации до оплаты. Для сравнения двух рекламных запусков с известными ссылками откройте отдельно [отчёты по рекламе](../advertising/reporting.md).

## Выбрать аудиторию и даты

Выберите готовый период или задайте свой диапазон. Обе выбранные даты входят в отчёт, сутки считаются по UTC. **Новые** зарегистрировались в пределах выбранного диапазона, **Существующие** пришли до его начала, **Все** объединяет обе группы. Например, для оценки продаж среди прежних клиентов выберите **Существующие** и последний месяц.

## Прочитать этапы

| Этап | Что попадает в счётчик |
| --- | --- |
| Регистрация | Пользователь зарегистрировался в выбранном диапазоне. Для существующей аудитории здесь будет ноль. |
| Пробный период | У пользователя зафиксирована активация триала. Простое открытие страницы триала не учитывается. |
| Создали счёт | Пользователь создал платёж. Несколько попыток одного человека дают одного пользователя на этапе. |
| Оплатили | У пользователя была успешная оплата за период. |

**Этапы** показывают охват и изменение относительно предыдущего этапа. За основание общей конверсии берётся первый непустой этап. Счётчики отражают события в периоде. Покупка может состояться без триала или по счёту из прошлого периода, поэтому столбцы могут расти и уменьшаться.

Переключитесь на **Динамика**, чтобы найти день изменения, или сгруппируйте график по неделям и месяцам. Блок **Источники трафика** распределяет регистрации по прямым, реферальным и партнёрским. В блоке платёжных систем доля считается по успешным платежам. Подробности по суммам и успешности всех попыток есть в [бизнес-аналитике](./analytics.md).
