# История изменений Minishop PRO

Здесь собраны изменения плагина и совместимые версии Minishop. Сначала идут изменения в разработке, затем опубликованные выпуски от новых к старым. Даты приведены в UTC по исходной публикации. Обновления самого магазина описаны в [основном списке изменений](../../../CHANGELOG.md).

## В разработке · dev

### Установка

- Подписанный ZIP включает клиент для входа в ChatGPT. AI-поддержку можно подключить на штатном worker Minishop и обновлять вместе с остальным плагином.

### Производительность

- Оптимизирован расчёт клиентских оценок и калибровки скоринга по следующей успешной оплате.
- Снижена фоновая нагрузка AI-поддержки в периоды без новых обращений.

## v0.1.36 — 2026-11-21

Совместим с Minishop 3.8.6.

- В боковом меню и журнале запуска отображается версия Minishop, на которой собран выпуск. Для установки опубликован обновлённый комплект образов и подписанный пакет PRO.

## v0.1.35 — 2026-11-20

Совместим с Minishop 3.8.6.

- Совет AI в карточке тикета теперь регистрируется и при установке PRO из подписанного пакета. Для установки из образов доступен файл точного выпуска. [Работа с тикетами](./ai-tickets.md).

## v0.1.33 — 2026-11-13

Совместим с Minishop 3.8.5.

- Разделы PRO приведены к оформлению новой админки. Обновлено превью расширения в разделе плагинов.

## v0.1.32 — 2026-11-02

Совместим с Minishop 3.8.4.

- В профиле клиента намерение купить и фактическая активность VPN показаны отдельно. Лента помогает видеть, какие сведения подтверждают оценку. В тикете готовый ответ AI можно прочитать до раскрытия технической диагностики. [Профиль клиента](./customers.md).

## v0.1.31 — 2026-10-22

Совместим с Minishop 3.8.3.

- После входа в аккаунт ChatGPT каталог и проверка модели обновляются автоматически. Кнопки, ведущие к установке приложения, сохраняют выбранную цель при использовании в PRO. [Подключение модели](./ai-setup.md).

## v0.1.30 — 2026-10-14

Совместим с Minishop 3.8.2.

- В настройках плагина появились подключение AI через API или аккаунт ChatGPT, база знаний в Markdown и режимы ответов. В тикете оператор может запросить приватный совет, посмотреть доступные сведения об аккаунте и перенести ответ с кнопками в редактор. [Настройки AI](./ai-setup.md) и [работа оператора](./ai-tickets.md).

## v0.1.29 — 2026-10-06

Совместим с Minishop 3.8.1.

- Восстановлено редактирование шагов автоматизации при установке плагина из пакета. [Редактор шагов](./delivery.md).

## v0.1.27 — 2026-10-06

Совместим с Minishop 3.8.1.

- В лиды и автоматизации добавлены фильтры по рекламной кампании, ссылке и UTM. В профиле клиента доступны источники первого обращения, последнего касания и оплаченной покупки. Обновлены карточка клиента и лента на узком экране. [Рекламные аудитории](./audiences.md).

## v0.1.26 — 2026-09-30

Совместим с Minishop 3.8.0.

- Исправлен запуск серверного образа с пользователем, заданным базовой сборкой Minishop. Это затрагивает установки из комплекта образов.

## v0.1.25 — 2026-09-30

Совместим с Minishop 3.8.0.

- PRO можно установить из подписанного пакета для совместимого магазина. Лицензия доступна в настройках плагина, а тексты PRO сгруппированы в редакторе переводов. Блоки бизнес-отчёта загружаются параллельно. [Варианты установки](./setup.md).

Совместим с Minishop 3.7.2.

## v0.1.23 — 2026-09-14

Совместим с Minishop 3.7.1.

## v0.1.22 — 2026-09-10

Совместим с Minishop 3.7.0.
