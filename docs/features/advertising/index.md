# Реклама и источники покупателей

В админке откройте **Реклама**, создайте кампанию и выберите **Открыть кампанию**.
Карточка объединяет ссылки, предложения, контакты, расходы, импорт и историю изменений.
Веб-ссылки работают и при отключённом Telegram.

Сначала создайте отдельную ссылку для каждого объявления. Затем проверьте переход,
авторизацию и покупку на тестовом аккаунте. Расходы можно ввести вручную или импортировать;
в настройках кампании выбирается один источник расходов.
