# Импорт показателей рекламного кабинета

Откройте **Импорт CSV**, выберите файл или вставьте текст, задайте рекламный аккаунт,
часовой пояс, разделитель и гранулярность. Затем явно сопоставьте колонки.
Обязательны начало интервала или время события и ID объявления.
Показы, клики, старты и расход необязательны. Для расхода требуется валюта.

Пример искусственного дневного файла:

```csv
date,ad,impressions,clicks,starts,cost,currency
2026-09-01T00:00:00Z,example-1,1000,50,12,500,RUB
```

Лимит файла — 1 MiB и 5 000 строк. Поддерживаются BOM, запятая, точка с запятой и табуляция.
Дата должна быть ISO 8601. Для локального времени применяется выбранный часовой пояс;
неоднозначное время при переходе DST требует явного смещения.
Неправильная строка отклоняет весь файл: частичное применение не происходит.

**Предпросмотр** ничего не добавляет к итогам. **Подтвердить весь импорт** применяет проверенные строки.
Повторное подтверждение того же импорта не дублирует показатели.
Исправленный файл требует выбора замены совпадающих интервалов.
Пересекающиеся интервалы разной гранулярности нельзя сложить или молча заменить.
**Отменить импорт** исключает его показатели и восстанавливает прежнюю подтверждённую версию.

Сопоставление людей доступно только для отдельных событий с временем.
Укажите ID бота и окно в секундах. Кандидаты включают органические старты и другие кампании.
Близость времени не доказывает личность; даже подтверждение оператором остаётся предположением
и не запускает выдачу прав или денежных вознаграждений.

Адаптер с явным сопоставлением колонок не является обещанием поддержки любого экспорта Telegram Ads.
Для проверки конкретного кабинета нужен обезличенный файл этого кабинета.
Связанные темы: [отчёты](./reporting.md), [диагностика](./troubleshooting-limitations.md).

API также принимает `text/csv` на `/api/admin/ads/{campaign_id}/imports/preview`: метаданные
и JSON-сопоставление `mapping` передаются в query, файл — в теле запроса. Для браузерной формы
CSV и метаданные отправляются одним структурированным JSON-запросом.

Отсутствующая колонка или пустая ячейка показов, кликов либо стартов означает отсутствие данных. Это отличается от явно указанного `0`. Неполные агрегаты показываются как «нет данных»; CTR без обеих величин не рассчитывается.
