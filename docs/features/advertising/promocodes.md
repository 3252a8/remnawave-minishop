# Предложения по рекламной ссылке

В разделе **Предложения** привяжите существующий код активации к кампании или отдельной ссылке.
Рекламный раздел использует обычный механизм кодов: срок действия, область применения,
лимит активаций и пользовательские ограничения продолжают проверяться при применении.
Персональный код одного пользователя нельзя опубликовать как предложение кампании.

Предложение с эффектом checkout подставляется в форму оформления заказа.
Пользователь может заменить код вручную. Предложение с самостоятельным бонусом
заполняет поле активации; для выдачи бонуса требуется действие пользователя.
Сам переход не выдаёт подписку, баланс или реферальное вознаграждение.

Выберите **Источник ручного ввода**, если код должен определять источник заказа даже без ссылки.
Это работает только при одной однозначной активной привязке к кампании.
Общий код нескольких кампаний не определяет источник сам по себе.
Подходящий контакт по ссылке имеет приоритет над ручным кодом.

Привязки версионируются. Новая привязка завершает предыдущую для той же области.
Изменение условий кода сохраняет прежнюю версию, а заказ хранит снимок действовавших условий.
История привязок и отдельные счётчики активаций, покупок, ожидающих заказов и возвратов
помогают отличать работу предложения от регистрации по рекламному источнику.

Подробнее о самих кодах: [коды активации](../promocodes.md).
О расчёте денежных показателей: [отчёты](./reporting.md).
