# Awesome Minishop: превью

Данные каталога: `docs-site/src/data/awesomeMinishop.ts`. Страница: `/awesome-minishop/`.
Изображения хранятся локально, чтобы каталог не зависел от внешнего хостинга картинок.

Превью тем взяты из публичных репозиториев авторов 2 октября 2026 года и оптимизированы
в WebP без изменения содержания. Автор и ссылка на проект показаны на каждой карточке.

| `solar.webp` | <https://github.com/austnv/minishop-themes/blob/master/themes/solar/preview.png> |
| `universe.webp` | <https://github.com/austnv/minishop-themes/blob/master/themes/universe/preview.png> |

`kiro-wheel.svg` и `ai-support.svg` — оригинальные иллюстративные обложки этого каталога,
а не скриншоты проектов. Это также указано в альтернативном тексте изображений.

Для нового проекта добавьте запись в соответствующую категорию, локальное превью
(рекомендуемое соотношение сторон 8:5), информативный `previewAlt` и источник изображения
в эту таблицу. Полные изображения открываются по нажатию на превью.

Иконки категорий — Google Noto Emoji. Анимация сохранена при уменьшении до 112×112;
`category-*-static.webp` — первые кадры для `prefers-reduced-motion`.

Звёзды: начальный снимок публичных API хранится в `repositoryStars` с датой `starsVerifiedAt`.
В браузере счётчики обновляются через публичные GitHub/GitLab API и кэшируются на шесть часов.
Для трёх тем одного репозитория выполняется один общий запрос. При недоступности API
остаётся начальный снимок с датой в подсказке.
